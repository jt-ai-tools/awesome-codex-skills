# 團隊 Wiki 資料庫 (Team Wiki Database)

**目的**：集中管理團隊知識與資源。

## 結構綱要 (Schema)

| 屬性 | 型別 | 選項 | 目的 |
|----------|------|---------|---------|
| **標題** | title | - | 頁面名稱 |
| **章節** | select | 快速開始, 流程, 工具, 參考資料, 新人入職 (Onboarding) | Wiki 組織架構 |
| **標籤** | multi_select | - | 主題標籤 |
| **負責人** | people | - | 頁面維護者 |
| **最後更新** | last_edited_time | - | 自動追蹤更新時間 |
| **可見性** | select | 公開, 僅限團隊, 機密 | 存取權限等級 |

## 使用方式

用於不適用於其他資料庫的團隊特定技術文件。

## 最佳實踐

1. **按章節組織**：使用清晰的高階組織架構。
2. **指派負責人**：每個頁面都應有一位維護者。
3. **控制可見性**：設定適當的存取權限。
4. **廣泛建立連結**：連接相關的頁面。
5. **保持內容時效性**：定期審查以移除過時內容。
