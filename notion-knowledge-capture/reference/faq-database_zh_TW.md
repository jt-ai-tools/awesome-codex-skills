# 常見問題資料庫 (FAQ Database)

**目的**：組織常見問題及其對應的回答。

## 結構綱要 (Schema)

| 屬性 | 型別 | 選項 | 目的 |
|----------|------|---------|---------|
| **問題** | title | - | 使用者詢問的問題 |
| **類別** | select | 產品, 工程, 支援, 人資, 一般 | 問題所屬主題 |
| **標籤** | multi_select | - | 特定主題（auth, billing, onboarding 等） |
| **回答類型** | select | 快速回答, 詳細指南, 連結至文件 | 回應的格式 |
| **最後審查日** | date | - | 回答經過驗證的時間 |
| **實用次數** | number | - | 追蹤有用程度（選填） |
| **受眾** | select | 內部, 外部, 全體 | 誰可以看到此內容 |
| **相關問題** | relation | 連結至相關 FAQ | 關聯相似的主題 |

## 使用方式

```
建立包含以下屬性的 FAQ 項目：
{
  "問題": "如何重設我的密碼？",
  "類別": "支援",
  "標籤": "authentication, password, login",
  "回答類型": "快速回答",
  "最後審查日": "2025-10-01",
  "受眾": "外部"
}
```

## 內容模板

每個 FAQ 頁面應包含：
- **簡短回答**：1-2 句話的快速回應。
- **詳細說明**：包含背景資訊的完整回答。
- **步驟**（若適用）：編號的操作程序。
- **螢幕截圖**（若有幫助）：視覺引導。
- **相關問題**：指向相似 FAQ 的連結。
- **額外資源**：外部文件或影片連結。

## 檢視表 (Views)

**按類別分類**：按類別進行分組。
**最近更新**：按「最後審查日」降序排列。
**需要審查**：過濾「最後審查日」早於 180 天前的項目。
**外部 FAQ**：過濾受眾包含「外部」的項目。
**熱門問題**：按「實用次數」降序排列（若有追蹤）。

## 最佳實踐

1. **使用清晰的問題**：以使用者實際詢問的方式撰寫問題。
2. **提供快速回答**：先提供直接的答案，隨後再詳述細節。
3. **連結相關 FAQ**：協助使用者發現相關資訊。
4. **定期審查**：確保回答與現況一致且準確。
5. **追蹤實用程度**：利用回饋來改進頻繁存取的 FAQ 內容。
