# 操作指南資料庫 (How-To Guide Database)

**目的**：紀錄常見任務的程序性文件。

## 結構綱要 (Schema)

| 屬性 | 型別 | 選項 | 目的 |
|----------|------|---------|---------|
| **標題** | title | - | 「如何 [任務名稱]」 |
| **複雜度** | select | 初階, 中階, 進階 | 所需的技能等級 |
| **所需時間** | number | - | 預估完成所需的分鐘數 |
| **前置要求** | relation | 連結至其他指南 | 開始前需具備的知識/條件 |
| **類別** | select | 開發, 部署, 測試, 工具 | 任務類別 |
| **最後測試日** | date | - | 操作程序經過驗證的時間 |
| **標籤** | multi_select | - | 技術或工具標籤 |

## 使用方式

```
建立包含以下屬性的操作指南：
{
  "標題": "如何設定本地開發環境",
  "複雜度": "初階",
  "所需時間": 30,
  "類別": "開發",
  "最後測試日": "2025-10-01",
  "標籤": "setup, environment, docker"
}
```

## 最佳實踐

1. **使用一致的命名**：標題始終以「如何...」開頭。
2. **測試操作程序**：在發布前驗證所有步驟皆可正常運作。
3. **包含預估時間**：協助使用者規劃時間。
4. **連結前置要求**：明確標示各項依賴關係。
5. **定期更新**：當工具或系統變更時，重新測試操作程序。
