# 潛在客戶研究助理 (Lead Research Assistant)

此技能透過分析您的產品/服務、瞭解您的理想客群畫像 (ICP)，並提供可執行的開發策略，協助您識別並篩選出適合您業務的潛在客戶 (Leads)。

## 何時使用此技能

- 為您的產品/服務尋找潛在客戶或買家
- 建立一份可進行合作洽談的公司清單
- 為銷售外連 (Outreach) 識別目標帳戶
- 研究符合您理想客群畫像的公司
- 為業務開發 (BD) 活動做準備

## 此技能的功能

1. **瞭解您的業務**：分析您的產品/服務、價值主張與目標市場。
2. **識別目標公司**：根據以下條件尋找符合您理想客群畫像的公司：
   - 行業與領域
   - 公司規模與所在地
   - 他們使用的技術堆疊 (Tech stack) 與工具
   - 成長階段與融資狀況
   - 您的產品能解決的痛點
3. **優先級排序**：根據契合度評分與相關性對公司進行排名。
4. **提供接洽策略**：建議如何使用個性化訊息與每位潛在客戶接觸。
5. **數據補充**：收集有關決策者與公司背景的相關資訊。

## 如何使用

### 基本用法

只需描述您的產品/服務以及您正在尋找的對象：

```
我正在開發 [產品描述]。幫我在 [地點/行業] 尋找 10 家適合作為此產品潛在客戶的公司。
```

### 配合您的程式碼庫

為了獲得更好的結果，請在您產品的原始碼目錄中執行：

```
查看我在這個儲存庫中建構的內容，並在 [地點/行業] 中識別出最能從此產品獲益的前 10 家公司。
```

### 進階用法

進行更具針對性的研究：

```
我的產品：[描述]
理想客群畫像 (ICP)：
- 行業：[行業]
- 公司規模：[人數/規模範圍]
- 地點：[地點]
- 目前痛點：[痛點描述]
- 他們使用的技術：[技術架構]

幫我尋找 20 個合格的潛在客戶，並為每個客戶提供接洽策略。
```

## 指令說明

當使用者請求潛在客戶研究時：

1. **瞭解產品/服務**
   - 如果在程式碼目錄中，分析程式碼庫以瞭解產品。
   - 針對價值主張提出澄清性問題。
   - 識別核心功能與效益。
   - 瞭解它能解決什麼問題。

2. **定義理想客群畫像 (ICP)**
   - 確定目標行業與領域。
   - 識別公司規模範圍。
   - 考慮地理位置偏好。
   - 瞭解相關痛點。
   - 紀錄任何技術需求。

3. **研究並識別潛在客戶**
   - 搜尋符合條件的公司。
   - 尋找需求訊號（徵才公告、技術堆疊、近期新聞）。
   - 考慮成長指標（融資、擴張、招聘）。
   - 識別擁有互補產品/服務的公司。
   - 檢查預算指標。

4. **優先級排序與評分**
   - 為每個潛在客戶建立契合度評分 (1-10)。
   - 考慮以下因素：
     - 與 ICP 的對齊程度
     - 即時需求訊號
     - 預算可用性
     - 競爭格局
     - 時機指標

5. **提供可執行的輸出**
   
   針對每個潛在客戶，提供：
   - **公司名稱**與網址
   - **為什麼契合**：根據其業務狀況給出具體理由
   - **優先級評分**：1-10 分並附帶解釋
   - **目標決策者**：建議接觸的職位/頭銜（例如「工程副總裁 VP of Engineering」）
   - **接洽策略**：個性化的接觸建議
   - **價值主張**：您的產品如何解決他們的具體問題
   - **對話切入點**：在外連時可以提及的具體細節
   - **LinkedIn 網址**：如有，以便輕鬆建立聯繫

6. **格式化輸出**

   以清晰、易讀的格式呈現結果：

   ```markdown
   # 潛在客戶研究結果報告
   
   ## 摘要
   - 找到的潛在客戶總數：[X]
   - 高優先級 (8-10)：[X]
   - 中優先級 (5-7)：[X]
   - 平均契合度評分：[X]
   
   ---
   
   ## 潛在客戶 1：[公司名稱]
   
   **官方網站**：[網址]
   **優先級評分**：[X/10]
   **所屬行業**：[行業]
   **公司規模**：[員工人數/營收範圍]
   
   **為什麼契合**：
   [根據其業務給出 2-3 個具體原因]
   
   **目標決策者**：[職位/頭銜]
   **LinkedIn**：[網址，如有]
   
   **對他們的價值主張**：
   [針對此公司的具體效益]
   
   **開發策略**：
   [個性化方法 - 提及具體痛點、近期公司新聞或相關背景]
   
   **對話切入點 (Conversation Starters)**：
   - [具體重點 1]
   - [具體重點 2]
   
   ---
   
   [針對每個潛在客戶重複上述內容]
   ```

7. **提供後續建議**
   - 建議將結果儲存為 CSV 以便匯入 CRM。
   - 提議草擬個性化的開發郵件。
   - 建議根據時機進行優先級排序。
   - 針對頂尖潛在客戶建議進行更深入的後續研究。

## 範例

### 範例 1：來自 Lenny's Newsletter 的案例

**使用者**：「我正在開發一個工具，可以在 AI 編碼助手的查詢中遮罩敏感數據。幫我尋找潛在客戶。」

**輸出**：建立一份優先級清單，包含符合以下條件的公司：
- 使用 AI 編碼助手（Copilot, Cursor 等）。
- 處理敏感數據（金融科技、醫療保健、法律）。
- 在其 GitHub 儲存庫中有使用編碼代理人 (Coding agents) 的證據。
- 可能曾在程式碼中意外洩漏敏感數據。
- 包含相關決策者的 LinkedIn 網址。

### 範例 2：在地業務

**使用者**：「我經營一家針對遠距團隊生產力的諮詢公司。幫我在灣區尋找 10 家最近轉向遠距辦公的公司。」

**輸出**：識別符合以下條件的公司：
- 最近發布了遠距職位需求。
- 宣布了遠距優先 (Remote-first) 政策。
- 正在招聘分散式團隊。
- 展現出遠距工作挑戰的跡象。
- 為每家公司提供個性化的開發策略。

## 獲得最佳結果的提示

- **具體說明**您的產品及其獨特價值。
- 如果適用，請**從您的程式碼庫執行**以自動獲取背景資訊。
- **提供背景資訊**說明您的理想客群畫像 (ICP)。
- **指定限制條件**，如行業、地點或公司規模。
- **要求針對承諾的潛在客戶進行後續研究**以獲取更深層的洞察。
