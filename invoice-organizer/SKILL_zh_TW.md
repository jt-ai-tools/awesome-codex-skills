# 發票與收據整理工具 (Invoice Organizer)

此技能可將混亂的發票、收據與財務文件資料夾轉化為整潔、符合報稅需求的歸檔系統，完全無需手動操作。

## 何時使用此技能

- 準備報稅季節並需要整理紀錄
- 管理多個供應商的業務支出
- 整理來自雜亂資料夾或郵件下載的收據
- 為持續性的記帳工作設定自動化發票歸檔
- 按年份或類別封存財務紀錄
- 為了費用報銷 (Reimbursement) 進行對帳
- 為會計師準備相關文件

## 此技能的功能

1. **讀取發票內容**：從 PDF、圖片與文件中擷取資訊：
   - 供應商/公司名稱
   - 發票號碼
   - 日期
   - 金額
   - 產品或服務描述
   - 付款方式

2. **一致地重新命名檔案**：建立標準化的檔名：
   - 格式：`YYYY-MM-DD 供應商 - 發票號碼 - 產品或服務.pdf`
   - 範例：`2024-03-15 Adobe - Invoice - Creative Cloud.pdf`

3. **按類別整理**：分類到邏輯資料夾中：
   - 按供應商
   - 按支出類別（軟體、辦公用品、差旅等）
   - 按時間段（年、季、月）
   - 按稅務類別（可扣抵、個人支出等）

4. **處理多種格式**：支援：
   - PDF 發票
   - 掃描收據 (JPG, PNG)
   - 郵件附件
   - 螢幕截圖
   - 銀行對帳單

5. **保留原始檔案**：在整理副本的同時保留原始檔案。

## 如何使用

### 基本用法

導航到您雜亂的發票資料夾：
```
cd ~/Desktop/receipts-to-sort
```

然後詢問 Claude Code：
```
幫我整理這些報稅用的發票
```

或更具體地要求：
```
讀取此資料夾中的所有發票，將它們重新命名為 
"YYYY-MM-DD 供應商 - 發票號碼 - 產品.pdf" 格式，
並按供應商進行分類
```

### 進階整理

```
整理這些發票：
1. 從每個檔案中擷取日期、供應商與描述
2. 重新命名為標準格式
3. 按支出類別（軟體、辦公用品、差旅等）分類到資料夾中
4. 為我的會計師建立一個包含所有發票詳情的 CSV 試算表
```

## 指令說明

當使用者請求發票整理時：

1. **掃描資料夾**
   
   識別所有發票檔案：
   ```bash
   # 尋找所有發票相關檔案
   find . -type f \( -name "*.pdf" -o -name "*.jpg" -o -name "*.png" \) -print
   ```
   
   回報發現：
   - 檔案總數
   - 檔案類型
   - 日期範圍（如果能從檔名辨識）
   - 目前的整理狀態（或雜亂程度）

2. **從每個檔案擷取資訊**
   
   針對每份發票擷取：
   
   **從 PDF 發票**：
   - 使用文字擷取功能讀取發票內容
   - 尋找常見模式：
     - "Invoice Date:", "Date:", "Issued:" (發票日期)
     - "Invoice #:", "Invoice Number:" (發票號碼)
     - 公司名稱（通常在頂端）
     - "Amount Due:", "Total:", "Amount:" (應付金額/總計)
     - "Description:", "Service:", "Product:" (描述/服務/產品)
   
   **從圖片收據**：
   - 讀取圖片中的可見文字
   - 識別供應商名稱（通常在頂端）
   - 尋找日期（常見格式）
   - 尋找總金額
   
   **針對不清晰檔案的回退方案**：
   - 使用檔名線索
   - 檢查檔案建立/修改日期
   - 如果缺失關鍵資訊，則標記為需手動審查

3. **決定整理策略**
   
   若未指定，請詢問使用者偏好：
   
   ```markdown
   我找到了來自 [日期範圍] 的 [X] 份發票。
   
   您希望如何整理它們？
   
   1. **按供應商** (Adobe/, Amazon/, Stripe/, 等)
   2. **按類別** (Software/, Office Supplies/, Travel/, 等)
   3. **按日期** (2024/Q1/, 2024/Q2/, 等)
   4. **按稅務類別** (Deductible/可扣抵, Personal/個人, 等)
   5. **自訂** (描述您的結構)
   
   或者我可以使用預設結構：年份/類別/供應商
   ```

4. **建立標準化檔名**
   
   針對每份發票，按照此模式建立檔名：
   
   ```
   YYYY-MM-DD 供應商 - 發票號碼 - 描述.ext
   ```
   
   範例：
   - `2024-03-15 Adobe - Invoice - Creative Cloud.pdf`
   - `2024-01-10 Amazon - Receipt - Office Supplies.pdf`
   - `2023-12-01 Stripe - Invoice - Monthly Payment Processing.pdf`
   
   **檔名最佳實踐**：
   - 移除連字號以外的特殊字元
   - 正確地將供應商名稱大寫
   - 保持描述簡潔但具備意義
   - 使用一致的日期格式 (YYYY-MM-DD) 以利排序
   - 保留原始副檔名

5. **執行整理**
   
   在移動檔案前，展示計畫：
   
   ```markdown
   # 整理計畫 (Organization Plan)
   
   ## 建議結構
   ```
   Invoices/
   ├── 2023/
   │   ├── Software/ (軟體)
   │   │   ├── Adobe/
   │   │   └── Microsoft/
   │   ├── Services/ (服務)
   │   └── Office/ (辦公)
   └── 2024/
       ├── Software/
       ├── Services/
       └── Office/
   ```
   
   ## 變更範例
   
   變更前：`invoice_adobe_march.pdf`
   變更後：`2024-03-15 Adobe - Invoice - Creative Cloud.pdf`
   位置：`Invoices/2024/Software/Adobe/`
   
   變更前：`IMG_2847.jpg`
   變更後：`2024-02-10 Staples - Receipt - Office Supplies.jpg`
   位置：`Invoices/2024/Office/Staples/`
   
   處理 [X] 個檔案？ (yes/no)
   ```
   
   獲准後：
   ```bash
   # 建立資料夾結構
   mkdir -p "Invoices/2024/Software/Adobe"
   
   # 複製（不移動）以保留原始檔案
   cp "original.pdf" "Invoices/2024/Software/Adobe/2024-03-15 Adobe - Invoice - Creative Cloud.pdf"
   
   # 或者如果使用者偏好，則進行移動
   mv "original.pdf" "new/path/standardized-name.pdf"
   ```

6. **生成總結報告**
   
   建立一個包含所有發票詳情的 CSV 檔案：
   
   ```csv
   日期,供應商,發票號碼,描述,金額,類別,檔案路徑
   2024-03-15,Adobe,INV-12345,Creative Cloud,52.99,Software,Invoices/2024/Software/Adobe/2024-03-15 Adobe - Invoice - Creative Cloud.pdf
   2024-03-10,Amazon,123-4567890-1234567,Office Supplies,127.45,Office,Invoices/2024/Office/Amazon/2024-03-10 Amazon - Receipt - Office Supplies.pdf
   ...
   ```
   
   此 CSV 檔案對以下用途非常有用：
   - 匯入會計軟體
   - 與會計師共享
   - 費用追蹤與報告
   - 報稅準備

7. **提供完成總結**
   
   ```markdown
   # 整理完成！ 📊
   
   ## 總結
   - **已處理**：[X] 份發票
   - **日期範圍**：[最早] 至 [最晚]
   - **總金額**：$[金額總計] (如果已擷取金額)
   - **供應商**：[Y] 個不重複供應商
   
   ## 新結構
   ```
   Invoices/
   ├── 2024/ (45 個檔案)
   │   ├── Software/ (23 個檔案)
   │   ├── Services/ (12 個檔案)
   │   └── Office/ (10 個檔案)
   └── 2023/ (12 個檔案)
   ```
   
   ## 已建立檔案
   - `/Invoices/` - 已整理的發票
   - `/Invoices/invoice-summary.csv` - 用於會計的試算表
   - `/Invoices/originals/` - 原始檔案（如果是用複製方式）
   
   ## 需要審查的檔案
   [列出任何無法完整擷取資訊的檔案]
   
   ## 後續步驟
   1. 審核 `invoice-summary.csv` 檔案。
   2. 檢查「需要審查」資料夾中的檔案。
   3. 將 CSV 匯入您的會計軟體。
   4. 為未來的發票設定自動整理。
   
   報稅季準備就緒！ 🎉
   ```

## 範例

### 範例 1：報稅準備 (源自 Martin Merschroth)

**使用者**：「我有一個雜亂的發票資料夾要用於報稅。請適當地分類並重命名。」

**執行過程**：
1. 掃描資料夾：發現 147 個 PDF 與圖片。
2. 讀取每份發票以擷取：日期、供應商名稱、發票號碼、產品/服務描述。
3. 重命名所有檔案：`YYYY-MM-DD 供應商 - 發票號碼 - 產品.pdf`。
4. 分類至：`2024/Software/`, `2024/Travel/` 等。
5. 為會計師建立 `invoice-summary.csv`。
6. 結果：數分鐘內完成報稅用的發票整理。

### 範例 2：每月費用對帳

**使用者**：「按類別整理我上個月的業務收據。」

**輸出**：

## 常見整理模式

### 按供應商（簡單模式）
```
Invoices/
├── Adobe/
├── Amazon/
├── Google/
└── Microsoft/
```

### 按年份與類別（報稅友善模式）
```
Invoices/
├── 2023/
│   ├── Software/
│   ├── Hardware/
│   ├── Services/
│   └── Travel/
└── 2024/
    └── ...
```

### 按季度（詳細追蹤模式）
```
Invoices/
├── 2024/
│   ├── Q1/
│   │   ├── Software/
│   │   ├── Office/
│   │   └── Travel/
│   └── Q2/
```

### 按稅務類別（會計師專用模式）
```

├── Deductible/ (可扣抵)

│   └── Professional-Services/
├── Partially-Deductible/ (部分可扣抵)
│   └── Meals-Travel/

```

## 自動化設定

為了持續進行整理：

```
建立一個腳本來監控我的 ~/Downloads/invoices 資料夾，
並使用我們的標準命名與資料夾結構自動整理任何新的發票檔案。
```

這將建立一個持久的解決方案，在發票送達時立即進行整理。

## 專業提示 (Pro Tips)

1. **將郵件掃描為 PDF**：先使用「預覽程式」或類似軟體將電子郵件發票儲存為 PDF。
2. **一致性下載**：將所有發票儲存到同一個資料夾以便批次處理。
3. **每月例行整理**：按月整理發票，而非按年。
4. **備份原始檔**：在重新組織前先保留原始檔案。
5. **在 CSV 中包含金額**：對預算追蹤非常有用。
6. **標記扣抵狀態**：註明哪些支出可以抵稅。
7. **收據保留 7 年**：這是標準的稽核期。

## 處理特殊情況

### 資訊缺失
如果無法擷取日期/供應商：
- 標記檔案以供手動審核。
- 使用檔案修改日期作為回退方案。
- 建立 "Needs-Review/" 資料夾。

### 重複發票
如果同份發票出現多次：
- 比較檔案雜湊值 (Hashes)。
- 保留品質最高的版本。
- 在總結中註明重複項。

### 多頁發票
對於分散在多個檔案中的發票：
- 如果需要，請合併 PDF。
- 對各部分使用一致的命名。
- 如果發票被拆分，請在 CSV 中註記。

### 非標準格式
對於不尋常的收據格式：
- 盡可能擷取資訊。
- 盡可能標準化。
- 如果缺失關鍵資訊，請標記以供審核。
