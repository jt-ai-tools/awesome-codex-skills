# 里程碑總結模板 (Milestone Summary Template)

在完成重大階段或里程碑時使用此模板。

```markdown
## 第 [N] 階段完成：[日期]

### 主要成就
- [交付的重大項目 1]
- [交付的重大項目 2]

### 交付物 (Deliverables)
- <mention-page url="...">交付物 1</mention-page>
- [PR 或部署連結]

### 指標數據
- [相關指標 1]
- [相關指標 2]

### 學習心得
- [哪些進展順利]
- [哪些有待改進]

### 下一階段
將於 [日期] 開始 [階段名稱]
```
