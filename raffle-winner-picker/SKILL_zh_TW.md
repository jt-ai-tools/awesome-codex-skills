# 抽獎中獎者抽選工具 (Raffle Winner Picker)

此技能可從清單、試算表或 Google Sheets 中為贈獎活動與競賽隨機抽選中獎者。

## 何時使用此技能

- 舉辦社群媒體贈獎活動
- 在活動現場抽取獎項中獎者
- 隨機挑選問卷調查或測試的參與者
- 從競賽投稿中選出獲勝者
- 公平分配有限的名額或資源
- 隨機進行團隊分組

## 此技能的功能

1. **隨機抽選**：使用加密安全的隨機選擇演算法。
2. **多種來源**：支援 CSV、Excel、Google Sheets 或純文字清單。
3. **多位中獎者**：可挑選一位或多位中獎者。
4. **重複預防**：確保同一人不會重複中獎。
5. **透明結果**：清晰展示選擇過程。
6. **中獎者詳情**：顯示關於中獎者的所有相關資訊。

## 如何使用

### 從 Google Sheets 抽選

```
從此 Google Sheet 中隨機挑選一行，選出贈獎活動的中獎者：[試算表網址]
```

### 從本地檔案抽選

```
從 entries.csv 中隨機抽選 3 位中獎者
```

### 從文字清單抽選

```
從此清單中隨機挑選一位中獎者：
- Alice (alice@email.com)
- Bob (bob@email.com)
- Carol (carol@email.com)
...
```

### 多位中獎者

```
從 contest-entries.xlsx 中隨機挑選 5 位中獎者，並確保不重複
```

## 功能特性

### 公平抽選
- 使用安全的隨機數生成器。
- 無偏見或固定模式。
- 過程透明。
- 支援使用種子 (Seed) 重複執行（以便驗證）。

### 排除條件
```
隨機挑選一位中獎者，排除先前已中獎的人員：Alice, Bob, Carol
```

### 加權抽選
```
根據「條目」欄位進行加權機率抽選（1 個條目 = 1 張抽獎券）
```

### 候補者 (Runner-ups)
```
從清單中挑選 1 位中獎者與 3 位候補者
```

## 範例工作流程

### 社群媒體贈獎
1. 將 Google 表單的條目匯出至試算表。
2. 指令：「從 [網址] 隨機挑選一位中獎者」。
3. 驗證中獎者詳情。
4. 公開發布抽選結果與時間戳記。

### 活動抽獎
1. 建立包含參與者姓名與郵件的 CSV。
2. 指令：「從 attendees.csv 中隨機抽選 10 位中獎者」。
3. 匯出中獎者名單。
4. 直接發送電子郵件通知中獎者。

### 團隊分組
1. 準備參與者清單。
2. 指令：「將此清單隨機分配為 4 個等額團隊」。
3. 審查分配結果。
4. 分享團隊名冊。

## 提示 (Tips)

- **記錄過程**：儲存時間戳記與抽選方法。
- **公開宣布**：分享抽選細節以展現透明度。
- **檢查資格**：驗證中獎者是否符合競賽規則。
- **準備備案**：挑選候補者以防中獎者資格不符。
- **匯出結果**：儲存中獎者名單以供記錄。

## 隱私與公平性

✓ 使用加密安全的隨機性。
✓ 絕無人為操控可能。
✓ 記錄時間戳記以供驗證。
✓ 可提供種子 (Seed) 供第三方驗證。
✓ 尊重數據隱私。
