# 綜合報告格式 (Comprehensive Report Format)

**何時使用**：
- 正式的文件編寫需求。
- 戰略決策支援。
- 需要詳盡分析的複雜主題。
- 多方利害關係人需要達成對齊 (Alignment) 時。

## 特性

**長度**：1500 字以上。

**結構**：
- 執行摘要。
- 背景與上下文。
- 研究方法。
- 帶有子章節的詳細發現。
- 數據與證據章節。
- 影響（短期與長期）。
- 優先級排序的建議。
- 附錄。

## 模板

完整模板請參閱 [comprehensive-report-template_zh_TW.md](comprehensive-report-template_zh_TW.md)。

## 最適用於

- 深度分析與戰略決策。
- 正式文件規範要求。
- 具備多個面向的複雜主題。
- 當利害關係人需要大量背景資訊時。
- 董事會簡報或執行簡報。

## 範例使用案例

- 「針對我們的市場地位建立一份綜合分析報告」
- 「記錄資料庫遷移的完整技術調查」
- 「準備一份關於供應商選項的深度報告以供高階主管審閱」
- 「分析不同架構方案的優缺點」
