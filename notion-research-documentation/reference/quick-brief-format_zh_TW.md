# 快速簡報格式 (Quick Brief Format)

**何時使用**：
- 具時效性的請求。
- 主題簡單。
- 狀態更新。
- 快速參考需求。

## 特性

**長度**：200-400 字。

**結構**：
- 3-4 句話的摘要。
- 3-5 個關鍵要點。
- 簡短的行動項目清單。
- 簡要的來源清單。

## 模板

完整模板請參閱 [quick-brief-template_zh_TW.md](quick-brief-template_zh_TW.md)。

## 最適用於

- 需要快速回覆的請求。
- 簡單、直接的主題。
- 快速的狀態更新。
- 當時間比深度更重要時。
- 進行深入研究前的初步探索。

## 範例使用案例

- 「快速總結我們的 API 文件中有什麼內容」
- 「針對昨天的會議記錄提供一份快速簡報」
- 「那份規格書中的關鍵點有哪些？」
- 「請給我一份關於專案狀態的快速概覽」
