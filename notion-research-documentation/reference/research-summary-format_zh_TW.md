# 研究摘要格式 (Research Summary Format)

**何時使用**：一般研究請求，這是最常用的格式。

## 特性

**長度**：通常為 500-1000 字。

**結構**：
- 執行摘要（2-3 句話）。
- 3-5 個具備支持證據的關鍵發現。
- 詳細分析章節。
- 結論與下一步行動。
- 來源引用。

## 模板

完整模板請參閱 [research-summary-template_zh_TW.md](research-summary-template_zh_TW.md)。

## 最適用於

- 大多數通用研究請求。
- 標準文件編寫需求。
- 兼顧深度與可讀性。
- 當您需要全面但易於理解的資訊時。

## 範例使用案例

- 「研究我們的認證方案選項」
- 「我們的專案文件對 API 重新設計有什麼看法？」
- 「總結團隊關於行動端策略的討論內容」
- 「彙整關於我們部署流程的資訊」
