# 範例：團體旅遊研究與規劃 (Group Trip Research & Planning)

**使用者請求**： 「研究並規劃我們明年三月的日本朋友之旅 —— 共 6 人，預計玩 10 天」

## 工作流程執行

### 1. 搜尋現有筆記
```
Notion:notion-search
query: "日本 旅遊"
```
找到：日本旅遊指南（來自朋友）、東京餐廳推薦、京都寺廟指南。

### 2. 獲取並擷取建議
```
執行 Notion:notion-fetch (3 次)
```
**來自先前旅客的關鍵資訊**：
- 最佳時間：三月至四月（櫻花季）。
- 必看景點：東京、京都、大阪。
- 預算：每天 200-300 美金（中價位）。
- 住宿建議提前 3 個月預訂。
- 抵達前先購買 JR Pass。
- 熱門餐廳：壽司大 (Sushi Dai)、一蘭拉麵、新宿綱八天婦羅。

### 3. 研究與綜整
結合先前旅客的見解與以下研究：
- 機票選項與價格。
- 住宿類型（飯店、日式旅館、Airbnb）。
- 交通方式（JR Pass 是必備的）。
- 10 天行程架構。
- 預算明細。

### 4. 建立綜合計畫
```
Notion:notion-create-pages
parent: { page_id: "travel-plans-parent-id" }
pages: [{
  properties: {
    title: "2026 日本之旅 - 3 月 15-25 日 (10 天)"
  },
  content: "[包含行程、預算、提示等完整內容的旅遊計畫]"
}]
```

## 輸出範例

```markdown
# 2026 日本之旅 - 3 月 15-25 日 (10 天)

## 旅遊概覽
**日期**：2026 年 3 月 15-25 日（櫻花季 🌸）
**人數**：6 人 | **預算**：每人 3,000-4,000 美金

## 行程摘要

**第 1-3 天：東京 (Tokyo)**
- 抵達，探索澀谷、原宿、新宿。
- 參觀築地市場、皇居、淺草寺。
- 體驗東京夜生活、teamLab Borderless 藝術展。

**第 4-5 天：箱根 (Hakone)**
- 東京出發的一日遊。
- 溫泉體驗、富士山景觀、蘆之湖遊船。

**第 6-8 天：京都 (Kyoto)**
- 從東京搭乘新幹線前往。
- 伏見稻荷大社、金閣寺、嵐山竹林。
- 藝妓區（祇園）、傳統茶道體驗。

**第 9-10 天：大阪 (Osaka) + 返程**
- 大阪城、道頓堀美食區。
- 奈良一日遊（梅花鹿公園、東大寺）。
- 從大阪關西機場 (KIX) 搭機返程。

## 預算明細（每人估計）
- **機票**：$900-1,200 (來回)
- **住宿**：$700-1,000 (9 晚)
- **JR Pass**：$280 (7 日券)
- **伙食**：$500-700 (每天約 $50-70)
- **活動項目**：$300-400
- **當地交通**：$100
**總計**：$2,780-3,680

## 關鍵預訂事項
- **機票**：提前 3-4 個月訂購。
- **住宿**：現在預訂（櫻花季極為熱門）。
  - 東京：新宿區 (2 晚) + 淺草 (1 晚)
  - 京都：祇園區 (3 晚)
  - 大阪：難波區 (2 晚)
- **JR Pass**：出發前 2-3 週訂購。
- **餐廳**：提前 1 週預約（如壽司大或高階餐飲）。

## 必備提示
來源：<mention-page url="...">日本旅遊指南</mention-page>
- 抵達後租借隨身 WiFi 或購買 eSIM。
- 下載必備 App：Google 翻譯、Hyperdia（查詢鐵路）、Tabelog（餐廳評分）。
- 現金至上的國家 —— 可在 7-Eleven 的 ATM 提款。
- 進入寺廟、日式旅館與部分餐廳需脫鞋。
- 火車極為準時 —— 千萬不要遲到。
- 學習基本用語：arigatou (謝謝)、sumimasen (抱歉/打擾了)、itadakimasu (我要開動了)。

## 行李清單
- 舒適的走路鞋（每天平均 1 萬步以上）。
- 薄外套（三月氣溫約 13-18°C）。
- 一日遊用的小背包。
- 裝現金的隨身包。
- 行動電源。

- [ ] 預約團體規劃討論會。
```
