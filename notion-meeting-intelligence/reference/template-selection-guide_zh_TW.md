# 會議模板選擇指南 (Meeting Template Selection Guide)

根據您的會議類型選擇正確的模板。

## 模板概覽

| 會議類型 | 使用此模板 | 何時使用 |
|--------------|-------------------|-------------|
| 做出決策 | [決策會議 (Decision Meeting)](decision-meeting-template_zh_TW.md) | 需要評估選項並達成決策時 |
| 專案進度更新 | [狀態更新 (Status Update)](status-update-template_zh_TW.md) | 定期檢查、進度審查 |
| 產生創意 | [腦力激盪 (Brainstorming)](brainstorming-template_zh_TW.md) | 創意發想、問題解決 |
| 衝刺計畫 | [衝刺計畫 (Sprint Planning)](sprint-planning-template_zh_TW.md) | 規劃敏捷開發 (Agile) 衝刺任務 |
| 衝刺回顧 | [回顧 (Retrospective)](retrospective-template_zh_TW.md) | 反思已完成的工作 |
| 主管與部屬對談 | [1:1 會議 (1:1 Meeting)](one-on-one-template_zh_TW.md) | 定期的對談與檢查 |
| 每週團隊同步 | [狀態更新 (Status Update)](status-update-template_zh_TW.md) (簡化版) | 例行性的團隊同步 |

## 模板自訂化

所有模板皆可進行自訂：
- **簡化**：針對較短的會議進行精簡。
- **新增章節**：針對特定需求增加內容。
- **組合元素**：結合多個模板的優點。
- **調整語言**：使語氣符合您的團隊文化。

## 最佳實踐

1. **先選定模板**：在收集背景資訊前先決定類型。
2. **收集 Notion 內容**：搜尋並獲取相關頁面。
3. **加入研究內容進行強化**：在有價值的地方加入 Codex 洞察。
4. **根據需要進行調整**：使模板適應具體情境。
5. **儘早分享**：留給參與者足夠的時間進行預讀與審查。
