# 回顧會議模板 (Retrospective Template)

將此模板用於衝刺回顧 (Sprint Retrospectives) 與團隊回顧會議。

```markdown
# 衝刺 [#] 回顧 - [日期]

## 會議詳情
**日期**：[日期]
**團隊**：[團隊名稱]
**衝刺期間**：[衝刺日期]
**引導者 (Facilitator)**：[姓名]

## 衝刺總結 (Sprint Summary)

**衝刺目標**：[目標描述]
**目標達成情況**：是 / 部分 / 否

**已完成**：[#] 點數 (Points)
**速率 (Velocity)**：[#] 點數
**預計計畫**：[#] 點數

## 預讀資料 (Pre-Read)

**衝刺指標**：
- 已完成任務數：[#]
- 延續至下期的任務數：[#]
- 發現的 Bug 數：[#]
- 遇到的阻礙因素 (Blockers)：[#]

## 討論內容

### 哪些進展順利 (繼續保持 - Keep)

[會議期間團隊成員的輸入]

### 哪些進展不順 (停止執行 - Stop)

[會議期間團隊成員的輸入]

### 哪些值得嘗試 (開始執行 - Start)

[會議期間團隊成員的輸入]

### 感謝與表揚 (Shout-outs)

[團隊成員間的認可與鼓勵]

## 行動項目 (Action Items)

- [ ] [待實施的改進措施] - @[負責人] - 到期日：[日期]
- [ ] [流程變更] - @[負責人] - 到期日：[日期]

## 後續追蹤

**審查行動項目的日期**：[下次回顧會議日期]
```
