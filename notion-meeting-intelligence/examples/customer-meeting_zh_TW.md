# 範例：客戶會議準備 (Customer Meeting Prep)

**使用者請求**： 「為週四與 Acme Corp 的銷售會議做準備」

## 工作流程

### 1. 搜尋客戶資訊
```
Notion:notion-search
query: "Acme Corp"
```

找到：
- 初次通話的 CRM 筆記。
- 產品展示 (Demo) 回饋。
- 定價提案。
- 競爭對手分析。

### 2. 獲取詳情
```
Notion:notion-fetch (共 4 頁)
```

**關鍵背景資訊**：
- **公司**：500 人規模的金融科技 (Fintech) 新創公司，B 輪融資 (Series B)。
- **痛點**：手動工作流程、數據孤島 (Data silos)、規模化問題。
- **決策者**：CTO（技術）、產品副總裁 (VP Product)（使用者需求）、CFO（預算）。
- **時程**：需要在第一季前找到解決方案。
- **預算**：年費 5 萬至 7.5 萬美金範圍。
- **競爭狀況**：正評估我們 vs. 競爭對手 A 與競爭對手 B。

### 3. 加入研究背景
加入 Codex 研究內容：
- 金融科技產業的合規性要求。
- 金融產品常見的整合需求。
- B 輪公司典型的採購流程。

### 4. 建立內部預讀文件 (Pre-Read)
```
Notion:notion-create-pages
pages: [{
  properties: {
    title: "Acme Corp 會議 - 預讀文件 (內部專用)"
  },
  content: "# Acme Corp 會議 - 預讀文件 (內部專用)

## 公司概覽
**公司**：Acme Corp (500 人金融科技公司, B 輪融資)
**決策者**：CTO, 產品副總裁, CFO
來源：<mention-page url='...'>CRM 筆記</mention-page>

## 他們的痛點 → 我們的解決方案
- 手動工作流程 → 工作流自動化
- 數據孤島 → API 整合
- 規模化問題 → 企業級功能

## 競爭定位
**我們相對於競爭對手 A/B 的優勢**：
- 更好的整合生態系統 (Stripe, Plaid)。
- 更強大的合規功能。
- 更快的實作速度（4 週 vs 12 週）。

## 定價策略
建議：每年 6 萬美金（處於其預算的中間範圍）。

## 潛在異議與應對 (Objections & Responses)
..."
}]
```

### 5. 建立會議議程
```
Notion:notion-create-pages
pages: [{
  properties: {
    title: "Acme Corp - 產品展示與問答"
  },
  content: "# Acme Corp - 產品展示與問答

## 會議詳情
**日期**：2025 年 10 月 17 日週四 @ 2pm PST
**參與者**：CTO, 產品副總裁, CFO (Acme) | 銷售主管, 解決方案工程師 (我方)
**時長**：60 分鐘

## 目標
展示我們的平台如何解決 Acme 的工作流自動化與整合挑戰。

## 議程 (Agenda)

**1. 介紹** (5 分鐘)

**2. 瞭解當前工作流程** (10 分鐘)
- 當前痛點。
- 整合需求。
- 成功標準。

**3. 產品展示 (Demo)** (25 分鐘)
- 工作流自動化功能。
- API 整合 (Stripe, Plaid)。
- 安全性與合規功能。

**4. 定價與實作** (10 分鐘)

**5. 下一步行動** (10 分鐘)
"
}]
```

### 6. 連結資源
將議程頁面與 CRM 頁面、定價表及技術整合文件進行關聯。

## 產出結果

**內部預讀文件**：為銷售團隊提供完整背景資訊。
**客戶端議程**：專業的會議結構。
**兩者皆位於 Notion 中**，並附帶支持材料的連結。

## 關鍵成功因素
- 深入瞭解客戶的具體痛點。
- 研究了產業背景（金融科技合規性）。
- 將產品功能與其需求進行對映。
- 準備了競爭差異化優勢。
- 圍繞其使用案例規劃產品展示。
- 預先規劃了異議應對方案。
- 議程中具備清晰的下一步行動。
