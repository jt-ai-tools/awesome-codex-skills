# 範例：高階主管審查會議準備 (Executive Review Prep)

**使用者請求**： 「為週五的季度高階主管審查會議 (Quarterly Executive Review) 做準備」

## 工作流程執行

### 1. 搜尋背景資訊
```
Notion:notion-search
query: "Q4 目標" + "KPI" + "季度結果"
```

找到：
- 第四季 OKR 與進度。
- 產品指標儀表板。
- 工程團隊速率報告。
- 客戶回饋總結。

### 2. 獲取與分析內容
```
執行 Notion:notion-fetch (共 5 頁)
```

**關鍵指標**：
- **營收**：240 萬美元 ARR（達成第四季目標的 96%）。
- **客戶增長**：新增 145 名客戶（超過目標 120 名）。
- **流失率 (Churn)**：3.2%（低於目標 5%）。
- **產品**：發布了 3 項重大功能，2 項處於 Beta 階段。
- **工程**：94% 上線率 (Uptime)（低於 95% SLA 要求）。

### 3. 加入 Codex 研究背景
加入以下內容的背景資訊：
- SaaS 指標的產業基準 (Benchmarks)。
- 典型的第四季銷售模式。
- 高階主管簡報的最佳實踐。

### 4. 建立預讀文件 (內部專用)
```
Notion:notion-create-pages
title: "第四季審查 - 預讀文件 (內部專用)"
```

**預讀文件章節**：
- **執行摘要 (Executive Summary)**：表現強勁的一季，營收雖短少 4%，但客戶增長超標。
- **詳細指標**：所有 KPI 及其趨勢線。
- **亮點與成就 (Wins)**：產品發布、關鍵客戶開發。
- **面臨挑戰**：銷售管道 (Pipeline) 轉化率、工程團隊招聘進度。
- **第一季展望**：戰略優先事項。

### 5. 建立簡報議程
```
Notion:notion-create-pages
title: "第四季高階主管審查會議 - 議程"
```

**議程** (90 分鐘)：
- 第四季結果概覽 (15 分鐘)。
- 營收與增長深度探討 (20 分鐘)。
- 產品與工程更新 (20 分鐘)。
- 客戶成功案例分享 (15 分鐘)。
- 第一季戰略計畫 (15 分鐘)。
- 討論與問答 (15 分鐘)。

### 6. 連結支持文件
將此議程關聯至 OKR、指標儀表板以及第一季規劃文件。

## 產出結果

**內部預讀文件**：包含誠實評估的全面背景資訊。
**主管會議議程**：結構化的 90 分鐘簡報流程。
**兩者皆位於 Notion 中**，並附帶支持數據的連結。

## 關鍵成功因素
- 綜整了來自多個來源的數據（OKR、指標、回饋）。
- 加入了產業背景與基準指標。
- 建立了誠實的內部評估（不僅僅是報喜）。
- 議程結構清晰且具備時間分配。
- 連結至來源數據，以便在問答環節中進行向下鑽研 (Drill-down) 的分析。
