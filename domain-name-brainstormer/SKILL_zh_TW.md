# 網域名稱發想工具 (Domain Name Brainstormer)

此技能透過生成創意選項並檢查實際可註冊的網址，協助您為專案找到完美的網域名稱。

## 何時使用此技能

- 開始一個新專案或成立新公司
- 發布產品或服務
- 建立個人品牌或作品集網站
- 為現有專案重新命名 (Rebranding)
- 為側邊專案 (Side project) 註冊網域
- 當首選網域已被佔用時，尋找可用的替代方案

## 此技能的功能

1. **了解您的專案**：分析您正在建構的內容及其目標受眾。
2. **生成創意名稱**：建立相關且好記的網域選項。
3. **檢查註冊狀態**：驗證哪些網域在多個 TLD 中實際可用。
4. **多種域名後綴**：提供 .com, .io, .dev, .ai, .app 等建議。
5. **提供替代方案**：如果首選已被佔用，提供變化版本。
6. **品牌洞察**：解釋為什麼某些名稱效果良好。

## 網域命名提示

### 什麼是好的網域

✓ **短**：15 個字元以內最理想
✓ **好記**：容易回想與拼寫
✓ **朗朗上口**：在對話中容易唸出來
✓ **具描述性**：暗示您的業務內容
✓ **具品牌潛力**：足夠獨特以脫穎而出
✓ **不含連字號**：口頭分享更容易（避免使用 - ）

### TLD 指南

- **.com**：全球通用、具信任感，適合各類企業
- **.io**：科技新創、開發者工具
- **.dev**：開發者導向產品
- **.ai**：AI/ML 產品
- **.app**：行動或網頁應用程式
- **.co**：.com 的熱門替代方案
- **.xyz**：現代、具創意的專案
- **.design**：創意/設計工作室
- **.tech**：技術公司

## 範例工作流程

### 新創公司發布
1. 描述您的創業構想。
2. 獲取 10-15 個跨不同 TLD 的網域建議。
3. 查看註冊狀態與價格。
4. 挑選前 3 名。
5. 立即註冊。

### 個人品牌
1. 分享您的姓名與職業。
2. 獲取變化版本（firstname.com, firstnamelastname.dev 等）。
3. 同時檢查社群媒體帳號 (ID) 是否可用。
4. 在各平台註冊一致的品牌名稱。

### 產品命名
1. 描述產品與目標市場。
2. 獲取具創意、具品牌潛力的名稱。
3. 檢查商標衝突。
4. 驗證網域與社群帳號可用性。
5. 針對目標受眾測試名稱。

## 成功提示

1. **動作要快**：好的網域很快就會被搶走。
2. **註冊多個版本**：同時取得 .com 與 .io 以保護品牌。
3. **避免數字**：口頭溝通較困難。
4. **檢查社群媒體**：確保 @使用者名稱 也能使用。
5. **大聲唸出來**：測試是否容易發音。
6. **檢查商標**：確保沒有法律衝突。
7. **長期考慮**：5 年後這個名稱還適用嗎？

## 價格背景參考

在建議網域時，我會標註：
- 標準網域：約 $10-15/年
- 優質 TLD (.io, .ai)：約 $30-50/年
- 已被佔用網域：若有列出，則為市場價格
- 溢價域名：數百至數千美金
