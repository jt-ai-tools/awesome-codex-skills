# 圖像增強工具 (Image Enhancer)

此技能可優化您的圖像與螢幕截圖，使它們看起來更銳利、更清晰、更具專業感。

## 何時使用此技能

- 為部落格文章或文件改善截圖品質
- 在分享至社群媒體前增強圖像效果
- 為簡報或報告準備圖片
- 放大低解析度圖像
- 讓模糊的照片變得銳利
- 清理壓縮後的圖像失真

## 此技能的功能

1. **分析圖像品質**：檢查解析度、銳利度與壓縮失真。
2. **提升解析度**：智慧化放大圖像。
3. **改善銳利度**：增強邊緣與細節。
4. **減少失真**：清理壓縮痕跡與噪點。
5. **針對使用場景進行優化**：根據預期用途（網頁、印刷、社群媒體）進行調整。

**輸出**：

正在分析 screenshot-2024.png...

**靈感來自**：Lenny Rachitsky 在其電子報中的工作流程——用於其文章中的截圖。

## 提示 (Tips)

- 始終保留原始檔案作為備份。
- 對於螢幕截圖與數位圖像效果最佳。
- 可批次處理整個資料夾。
- 如有需要可指定輸出格式（PNG 追求品質，JPG 追求較小體積）。
- 對於社群媒體，請提及平台名稱以獲得最佳尺寸建議。

## 常見使用案例

- **部落格文章**：在發布前增強截圖效果。
- **文件手冊**：讓 UI 截圖變得極致清晰。
- **社群媒體**：針對 Twitter (X)、LinkedIn、Instagram 優化圖像。
- **簡報**：為大螢幕放大圖像。
- **印刷材料**：為實體媒介提高解析度。
