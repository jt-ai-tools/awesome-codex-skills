## 何時使用此技能

當您需要執行以下操作時，請使用此技能：
- **建立具備正確結構與中繼資料的新 Claude 技能**。
- **生成準備好分發的技能套件**。
- **自動在 Slack 頻道分享已建立的技能**以提高團隊能見度。
- **在分享前驗證技能結構**是否正確。
- **打包並分發**技能給您的團隊。

當出現以下情況時也請使用此技能：
- **使用者表示他想要建立或分享其技能**。

此技能非常適合：
- 作為團隊工作流程的一部分來建立技能。
- 建構需要「技能建立 + 團隊通知」功能的內部工具。
- 自動化技能開發管線 (Pipeline)。
- 帶有團隊通知功能的協作式技能建立。

## 關鍵功能

### 1. 技能建立
- 建立具備 `SKILL.md` 且結構正確的技能目錄。
- 生成標準化的 `scripts/`、`references/` 與 `assets/` 目錄。
- 自動生成帶有必填中繼資料的 YAML 前言 (Frontmatter)。
- 強制執行命名慣例（使用連字號分隔，hyphen-case）。

### 2. 技能驗證
- 驗證 `SKILL.md` 格式與必填欄位。
- 檢查命名慣例。
- 在打包前確保中繼資料的完整性。

### 3. 技能打包
- 建立可分發的 ZIP 壓縮檔。
- 包含所有技能資產與文件。
- 在打包前自動執行驗證。

### 4. 透過 Rube 整合 Slack
- 自動將已建立的技能資訊發送至指定的 Slack 頻道。
- 分享技能中繼資料（名稱、描述、連結）。
- 發布技能摘要以供團隊發現。
- 提供指向技能檔案的直接連結。

## 運作原理

1. **初始化**：提供技能名稱與描述。
2. **建立**：建立具備正確結構的技能目錄。
3. **驗證**：驗證技能中繼資料的正確性。
4. **打包**：將技能打包成可分發的格式。
5. **Slack 通知**：將技能詳情發布到您團隊的 Slack 頻道。

## 使用範例

```
當您要求 Claude 建立一個名為 "pdf-analyzer" 的技能時：
1. 建立包含 SKILL.md 模板的 /skill-pdf-analyzer/。
2. 生成結構化目錄 (scripts/, references/, assets/)。
3. 驗證技能結構。
4. 將技能打包為 ZIP 檔案。
5. 在 Slack 發文："建立新技能：pdf-analyzer - 進階 PDF 分析與擷取功能"。
```

## 與 Rube 的整合

此技能利用 Rube 執行以下操作：
- **SLACK_SEND_MESSAGE**：將技能資訊發送至團隊頻道。
- **SLACK_POST_MESSAGE_WITH_BLOCKS**：分享具備豐富格式的技能中繼資料。
- **SLACK_FIND_CHANNELS**：尋找用於發布技能公告的目標頻道。

## 使用要求

- 透過 Rube 連接 Slack 工作區。
- 具備技能建立目錄的寫入權限。
- 具備 Python 3.7+ 環境以執行技能建立腳本。
- 指向技能通知的目標 Slack 頻道。
